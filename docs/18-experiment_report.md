# experiment_report.py 详解 —— 论文式实验报告

## 为什么存在

`benchmark.py` 只能打印 40 个实例的对比数字,面试和论文需要的是**证据链**:
离最优差多少(有硬参照)、随规模怎么涨、哪个约束在制造难度(消融)。
这个脚本把评测升级成论文式报告:

1. 规模化: n=4→30, 每规模 8 个实例, 三算法共用同一批实例;
2. 硬参照: n≤8 全排列求暴力最优, gap 的分母是真的"全局最优";
3. 三个指标: gap%、墙钟耗时、候选解评价次数;
4. 消融实验: 时间窗开/关、优先级密度高/低, 隔离单一变量;
5. 输出: `experiment/实验报告.md` + 7 张图 + 缓存 JSON, 可复现可重出。

## 实验设计

### 实例生成(和 benchmark.py 完全一致)

`benchmark.make_instance` 随机生成,约束分布贴合真实解析器产出:
- 优先级 `[1,2,2,2,3]` 加权,时长 `[20,30,30,60,90]` 加权;
- 20% 固定预约, 70% 时间窗, 30% 加 deadline;
- 距离用直线估算(不消耗高德配额),固定种子 `SEED + n*100000 + k` 可复现。

### 指标定义

- **gap%** = (算法分 − 最优分) / 最优分 × 100, 分母是暴力枚举的全局最优;
- **耗时** = 墙钟时间(ms), 同进程同机器公平比较;
- **评价次数** = 候选顺序被 `evaluate_order` 评分的次数, 衡量计算量(与语言/机器无关)。

### 消融实验(严格隔离变量)

- **时间窗**: 同一批实例, 只是把 `earliest/latest/fixed/deadline` 全部置空,
  比较"保留 vs 去掉"——隔离出时间窗约束这一个变量;
- **优先级**: 同一批实例的坐标/时长/时间窗完全相同, 只把优先级改成全 3 / 全 1,
  隔离优先级的影响。

### 大 n 的诚实处理

n>8 暴力不可行(9!≈36 万), 报告明确标注:
- n=9~12 用"三者最优"当下界(真实 gap 只会更小);
- n=13~30 直接统计"谁拿到最好解"的胜场(图5)。

## 用法

```bash
python experiment_report.py            # 完整跑(数据+图+报告, 约 6 分钟)
python experiment_report.py --plot     # 只用缓存重出图/报告(改绘图代码不用重跑)
python experiment_report.py --smoke    # 冒烟(4 个规模 × 2 实例)
```

缓存: `experiment/data/*.json`; 图表: `experiment/charts/*.png`; 报告: `experiment/实验报告.md`。

## 结果解读(完整实验)

- n≤8 平均 gap: 启发式 **2.84%** / 模拟退火 **0.02%** / 遗传 **0.00%**(遗传全部命中暴力最优);
- n=9~30 胜场: 退火 59.1% / 遗传 15.9% / 启发式 11.4% / 并列 13.6%;
- 消融-时间窗: 启发式 gap 从 5.61% 降到 1.54%——**时间窗是难度主要来源**;
- 消融-优先级: 全 3 vs 全 1 几乎不变(负结果)——难度不在优先级, 改进应优先处理时间窗。

## 面试怎么讲

1. "我们有暴力最优做硬参照, 证明了遗传算法在小规模 gap<1%、退火更快更稳";
2. "用消融实验定位难度来源: 时间窗是主因, 这是负结果也照实报告, 证明实验可信";
3. "全部种子固定、缓存可重跑——可复现是论文实验的基本要求"。
