# db.py 详解 —— SQLite 地点记忆 / 历史计划 / 偏好

## 这个文件为什么存在

让系统"越用越懂你",需要持久化三类数据:

1. **places**:用过的地点(关键词 → 具体地点坐标),"去银行"下次直接给坐标或排进候选;
2. **plans**:历史计划(以后翻看/恢复,也是行为预测 ML 化的原始数据源);
3. **prefs**:按时段的回家休息偏好(早上/中午/下午/晚上想不想回家)。

**为什么选 SQLite 而不是 MySQL/文件**:零配置、单文件、Python 自带 `sqlite3` 模块,个人工具的数据量(几百条)完全够用。每行记录量级,不需要服务端。

## 表结构

### places —— 地点记忆
```sql
id, keyword, name, address, lat, lng, source, last_used
```
- `keyword` 是"银行"这种规范关键词,`name` 是具体店名("招商银行南京东路支行");
- 同一关键词可记多个地点,查的时候按 `last_used` 排序——这就是候选列表里"常用"的来源;
- `source` 标记 poi/geocode,调试用。

### plans —— 历史计划
```sql
id, created_at, mode, start_name, start_lat, start_lng, summary, stops_json
```
`summary`/`stops_json` 存 JSON 字符串,不拆列——查询时按整条恢复,拆列没有收益(不按字段过滤)。

### prefs —— 休息偏好
```sql
id, period, value   -- period 唯一, value = home/stay
```
`period` 唯一键 + `ON CONFLICT DO UPDATE`,天然是"按时段存一个值"的语义。

## 重点函数逐个说明

### `_conn()` —— 连接管理

每次操作独立开连接、用 `with`/`finally` 关掉。**没有长期持有的连接对象**:单用户 SQLite 场景,开连接成本可忽略,却避免了线程安全/连接泄漏的坑(Flask 默认多线程)。

### `init_db()` —— 建表

启动时调用(`app.py` 里 `db.init_db()`),`CREATE TABLE IF NOT EXISTS`,幂等。places 表建了 `idx_places_kw` 索引,查询关键词是主访问路径。

### `remember_place(keyword, name, lat, lng, ...)` —— 记地点

```python
DELETE FROM places WHERE keyword=? AND name=?
INSERT INTO places(...) VALUES(...)  -- last_used = 当前毫秒时间戳
```

**先删后插实现 upsert**:同关键词同地点重复使用时,删掉旧记录重新插入,`last_used` 自然刷新,不会有重复行。为什么不用 `UPDATE ... WHERE`?因为地址等字段可能变了(用户这次选了个新地址),先删后插能一次处理"新增"和"更新"两种情况。

### `search_places(keyword, limit)` —— 查地点

按 `last_used DESC` 排序,最近用的排最前。返回前 limit 个,给候选列表用。

### `save_plan / list_plans / get_plan / clear_plans`

历史计划的标准 CRUD:`list_plans` 只取列表字段(不含 `stops_json`,省传输),`get_plan` 取整行供恢复,`clear_plans` 一键清空(前端"🗑 清除记录"按钮)。

### `save_prefs(prefs)` / `load_prefs(prefs)`

```sql
INSERT INTO prefs(period, value) VALUES(?,?)
ON CONFLICT(period) DO UPDATE SET value=excluded.value
```
SQLite 的 upsert 语法,存四个时段偏好;加载时转成 `{period: value}` 字典。

## 安全与工程

- **参数化查询**:所有 SQL 用 `?` 占位符,杜绝注入——虽然单用户工具风险低,但这是习惯;
- **不存敏感信息**:坐标和文本没有任何隐私加密(本地工具),但如果以后要公开部署,`stops_json` 里的行程数据就是需要脱敏的对象;
- **`route.db` 已 gitignore**:运行数据不进仓库,首次运行自动重建。
