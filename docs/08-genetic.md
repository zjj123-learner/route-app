# genetic.py 详解 —— 遗传算法求解器

## 这个文件为什么存在

遗传算法(Genetic Algorithm)模拟"优胜劣汰":种群里的每条染色体(一个任务排列)按适应度(评价函数总分)竞争,通过**选择 + 交叉 + 变异**一代代进化,取历史最优个体。

**为什么在已有退火的情况下还要做遗传**:
1. 概念演示价值高——"进化"的故事在报告/面试里比退火更直观;
2. 天然可并行(每代个体独立评分);
3. 和退火互为对照,benchmark 里验证"两者互有胜负,没有谁全面碾压"——这是诚实实验的一部分。

## 超参数(自适应的默认值)

| 参数 | 默认 | 依据 |
|---|---|---|
| 种群大小 | 60 | 足够多样性,又不会太慢 |
| 代数 | `max(60, m×20)` | 自由任务越多,进化代数越多 |
| 锦标赛 k | 3 | 常见折中 |
| 精英保留 | 2 | 每代最好的 2 个原样进下一代,保证不退化 |
| 变异率 | 0.15 | 保持多样性又不破坏好解 |

## 重点函数逐个说明

### `_build_base(tasks, fixed_positions)` / `_full_order(...)`

与 `simanneal.py` 完全一致(刻意复制保持一致):锁定任务钉在固定槽位,遗传只对自由任务进化。这样"锁定"功能在三个算法下行为一致。

### `_tournament(scored, k, rng)` —— 锦标赛选择

随机抽 k 个染色体,留下适应度最好的当父母。比"轮盘赌"实现简单,选择压力可调(k 越大压力越大)。

### `_crossover(a, b, rng)` —— 顺序交叉(OX)

这是排列编码遗传算法的经典交叉:
1. 从父亲 a 取一段**原样保留**(保证局部好顺序不被打散);
2. 其余位置按母亲 b 的顺序依次补全(保证不重复、不遗漏)。

`gene not in child` 的判重是关键——排列问题交叉后必须仍是合法排列。

### `_mutate(chromo, rng)` —— 变异

一半概率交换两个位置,一半概率反转一段。反转比单点交换改变更大,两者配合保持种群多样性,防止过早同质化(早熟收敛)。

### `ga_route(...)` —— 主函数

1. 初始种群:1 个最近邻解 + 其余随机——**保证起点质量**,这是遗传算法容易踩的坑(全随机初始容易收敛慢);
2. 每代:全部个体算适应度 → 排序 → 锦标赛选父母 → 交叉 + 变异生成下一代 → 精英 2 个直接保留;
3. 全程记录历史最优染色体,最后返回它(不一定是最后一代的)。

返回结构和 `optimize_route`/`sa_route` 一致,`method` 标 "genetic"。

## 为什么说遗传"概念酷、可并行"但要谨慎用

- 优点:不需要邻域结构设计,交叉/变异算子通用;
- 缺点:超参数多(种群/代数/变异率/锦标赛),调起来比退火麻烦;对 9~30 这种小规模,和退火效果几乎一样,但实现和调参成本更高。
- benchmark 结论:小规模两者都 100% 找到暴力最优;大规模(9~12)互有胜负——**用遗传的收益在"讲清楚概念",不在"结果更好"**。
